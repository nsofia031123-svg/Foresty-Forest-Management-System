# 🌳 Forest Management System

A web-based forest management system developed using PHP and MySQL to analyze forest stand data, simulate different cutting regimes, and generate reports for sustainable forest management.

---

## 🎯 Features

* Forest Stand Analysis
* Tree Distribution Visualization
* Stand Table Generation
* Production Analysis
* Damage Analysis
* Remaining Stand Calculation
* Final Harvest Output
* Forest Information Dashboard

---

## 👥 User Roles

**User**

* View forest information
* Analyze stand data
* Simulate cutting regimes
* Generate stand tables
* View harvest analysis and reports

---

## 💻 Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Tools:** XAMPP, phpMyAdmin, Visual Studio Code
